# Skill Reading Guidance

Read the appropriate skills before starting work.

## For ANY Coding Task

Read **project-standards** skill for:
- Complete coding standards and critical rules
- Code translation rules (Laravel to Rails)
- Project structure details

## For Frontend/View Work

When working with views, ERB templates, helpers, CSS, or UI:

1. Read **design-rules** FIRST - Critical approval workflows
2. Read **design-foundations** - Color tokens, typography, spacing, dark mode
3. Read **design-components** - Button/card/table/modal helpers
4. Read **design-forms** - Form builder patterns (if forms involved)
5. Read **design-layouts** - Page patterns, breakpoints
6. Read **design-content** - Terminology, accessibility

## For Menu/Navigation Work

Read **menus** skill for navigation menu system and visibility rules.

## Reference Documents

For detailed API signatures, also consult:
- `docs/DESIGN-GUIDE.md` - Complete design system
- `docs/UI-COMPONENTS.md` - Helper method signatures
- `docs/form_helper.md` - Form builder API
